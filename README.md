Vice//Frame is a GTA-inspired poster editor for building neon Vice City cover art.

Run it with:

    python3 -m http.server 8123 --directory app

Then open http://127.0.0.1:8123/.

Controls:
- Choose a layout and visual look.
- Load sample photos or upload your own; select a photo chip for the active panel.
- Adjust grade, lettering, caption, decoration, and crop; drag the canvas to reposition.
- Choose an export size and click Download.

Export sizes: Square 1080×1080, Portrait 1080×1350, Landscape 1920×1080.

The bundled Bebas Neue font is used under the SIL Open Font License; see app/fonts/LICENSE-OFL.txt.
